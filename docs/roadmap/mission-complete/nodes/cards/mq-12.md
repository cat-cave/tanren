# mq-12 — Fragment/F2 evidence-contract extension

**Phase**: full (merge-queue)

**Node ID**: mq-12

**Deps**: mq-6, mq-7 · SP-2, SP-5

**Node credit**: 0 until independent audit + green gates + merge.

## Purpose and boundary

Add a frozen, declarative evidence contract to the existing F2 fragment artifact so batch proof selection can use an authored test/report/behaviour manifest without another authoring kernel or executable-command policy. This extends `FragmentContract` in `services/orchestrator/src/engine/templates/fragments/types.ts`, fail-closed selection in `selectFragmentConfig.ts`, and composition in `services/orchestrator/src/engine/templates/fragments/compose.ts`; it does not fork `createAuthoringKernel` in `engine/contracts/authoringKernel.ts` or `authoring/authoringKernelRunner.ts`.
The F2 path remains `deriveProductGraph.ts:resolveFragmentConfig` -> `runFragmentAuthoring` -> `selectFragmentConfig`, including its loud terminal failure for a missing fragment.

It builds on mq-6's live integration proof graph, not a parallel verifier: `BatchMergeCoordinator` -> `PgBatchChecker.check` -> `driveThroughIntegrationNode` -> `batchProofUnitGraph` -> `IntegrationProofUnitGraph.evaluate`, with `batchNodeGate.ts` retaining `runGateForWhen({ when: "pre_merge" })` as the full-gate fallback. `.tanren/ci.yml` remains the sole executable CI contract.

## Production call graph

Current authoring writes the selected fragment contract atomically through `fragmentAuthoringRun.ts:authorOneFragment` / `createValidated`; current composition processes `testRunner` and `reportPath` through `processCiYml`; current batch evaluation records/reuses proof units through `IntegrationProofUnitGraph.evaluate`.

The one new production entry point is `resolveFragmentEvidenceForBatch(workspace, fragment, proofRequest)`. `PgBatchChecker.driveThroughIntegrationNode` calls it immediately before existing proof-graph evaluation. It reads the selected F2 contract and composed repository-local evidence manifest, validates exact paths/digests, then supplies only a typed selector and declared artifact identity to the existing graph.
Absent, stale, malformed, or non-matching evidence calls the existing full `runGateForWhen` pre-merge path; it never constructs a shell command or skips the batch gate.

## Contract / Data model

Add `FragmentEvidenceContractV1Schema` (strict Zod, frozen `schemaVersion: "fragment_evidence.v1"`) beside the fragment types. Its closed fields are safe repository-relative JUnit report path, stable test-selector manifest path/format, behaviour-manifest path/format, and immutable content digest. Embed it as `FragmentContract.evidence`; unknown fields, absolute paths, traversal, command text, and shell snippets are invalid.
Composition emits deterministic declarative `.tanren/evidence-contract.json`; it adds no execution semantics.

No migration and no new table. The F2 artifact remains in existing fragment contract JSONB. Existing FORCE RLS `integration_proof_units` / edges / evaluations in `db/src/schemaIntegrationProofUnits.ts` retain proof ownership. Existing FORCE RLS `verification_artifacts` from `db/migrations/0037_runtime_behavior_verification.sql` records the captured artifact and existing CAS digest; when the proof is an integration proof unit, `proof_unit_digest` stays null rather than inventing a false FK.

## Provable / callable / visible

The authoring lifecycle continues to emit existing `fragment.authoring.started`, `fragment.authoring.attempt`, `fragment.authoring.succeeded`, and `fragment.authoring.failed`; evaluation continues to emit existing `integration.proof_unit.recorded` or `integration.proof_unit.reused`. No new event vocabulary is required.

Expose `GET /orgs/:orgId/projects/:projectId/merge-queue/evidence-contracts/:nodeId` from the existing merge-queue route family, returning the redacted frozen contract, resolution status, proof-unit identity, and fallback reason. Add an Evidence Contract panel to existing `/merge-queue` (`services/dashboard/src/routes/mergeQueue` and `components/mergeQueue/MergeQueueBody.tsx`), never a control that can run commands.

## Fail-closed proof

Invariant: a fragment-derived selector is usable only when frozen contract, exact composed manifest, report digest, workspace identity, and proof input agree; otherwise normal pre-merge runs in full. The gravest prohibited fail-open is accepting an authored selector as a pass while an unselected changed test can fail.

Local verification proves malformed/absent F2 evidence selects the full gate, preserves terminal `FragmentAuthoringFailedError`, and rejects traversal/command fields. The independent adversarial GO runs a negative-control changed test excluded from a claimed selector: the batch must fail, record no reusable selective success, and never reach MergeAuthority. Audit compares declared CAS digest with captured `verification_artifacts` digest and integration proof input hash.
